# Night City Web — 战斗系统 设计文档

**日期**: 2026-07-04
**状态**: 已批准
**前置**: 城市/行人/车流/业态系统均已就绪（见 2026-07-03 spec 与 git 历史）

## 1. 目标

把观光沙盒升级为**完整战斗沙盒**：

- 玩家是持械角色：4 武器槽（拳/手枪/冲锋枪/霰弹）、射击、换弹、切枪
- **全民血量**：玩家、帮派、NCPD、医疗、全体行人统一 HP=100，按武器伤害结算，可被击杀
- 街头可直接目击的暴力：斗殴、帮派枪战、NCPD 交火、死亡倒地
- 玩家会被还击、会被击倒、会重生；向平民/警察开火触发通缉
- 顺带修复：场所可发现性（门头文字 + M 键小地图）
- 表现分级：**风格化**（火花 + 短促红色粒子 + 倒地 20 秒淡出，无持久血渍）
- 音效：WebAudio 程序化合成（枪声/命中/换弹/受击），无外部资产

**非目标**：近战武器系统（拳头即近战）、载具驾驶、任务系统、存档、3 星以上通缉军警。

## 2. 架构决策：单层人海 + 确定性命中反算 + 活性战斗池

- 2.5 万 GPU 行人**保留**。行人位置是确定性公式 `start + dir × mod(t0 + speed·t, len)`，CPU 可随时反算精确位置 —— 命中判定对玩家周围（≤60m）行人按公式重建胶囊体即可，**零常驻开销**。
- 命中致死的人海行人：改写该实例的 InstancedBufferAttribute（speed→0）并把 instanceMatrix 写成命中点倒地姿态，20 秒后下沉淡出（矩阵 y 递减，由死亡管理器少量逐帧更新）。
- 会打架的 AI（帮派/NCPD 活性单位）用 **CPU 活性池 ~160 人**（独立 PedFleet 风格实例组，CPU 驱动矩阵），跑索敌/开火/散开 AI（0.1s 节流分帧）。
- 否决项：全 CPU 行人（违背万人街区）；纯脚本观赏战斗（不满足全民血量）。

## 3. 模块

```
src/combat/
├── damage.ts        # 纯逻辑：HP 表、伤害结算（部位系数）、死亡状态机（可测）
├── hitreg.ts        # 纯逻辑：射线 vs 胶囊 / vs 墙体 AABB 网格（可测）
├── weapons.ts       # 武器定义 + 开火状态机（射速/弹匣/换弹/散布，可测）
├── player.ts        # 玩家战斗态：HP/重生/输入（射击、1-4 切枪、R 换弹、滚轮）
├── viewmodel.ts     # 第一人称盒枪模型 + 枪口焰 + 后座抖动
├── tracers.ts       # 曳光弹/火花/红色粒子对象池
└── audio.ts         # WebAudio 程序化音效（枪/命中/换弹/受击/死亡提示）
src/people/gangs.ts  # 帮派定义、地盘、巡逻小队（活性池单位来源）
src/events/violence.ts # 暴力事件导演：斗殴/帮派枪战/NCPD 交火，同时 4-6 起
src/events/wanted.ts   # 通缉状态机（0/1/2 星，20s 视线外衰减，可测）
src/people/activeNpcs.ts # 活性 NPC 池：CPU 实体（位置/朝向/持枪/AI 状态）
src/ui/minimap.ts    # M 键小地图（canvas：路网/玩家/场所色点/事件红点）
src/ui/combatHud.ts  # 十字星/弹药/血条/通缉星/命中反馈
```

改动既有模块：
- `pedestrians.ts`：暴露 `resolvePedPosition(kindIdx, i, t)` 反算 + `killPed(kindIdx, i, at)` 写倒地 + 恐慌波 uniform（vec4×4：x,z,t0,r，半径内步速×3）
- `interiorKits.ts`/`lobbies.ts`：门头灯箱加文字小图集（吧/医/食/枪/网/宿/衣/仓/弹）
- `hud.ts`：并入战斗 HUD 挂点
- `main.ts`：战斗系统装配、漫游模式才启用武器

## 4. 数值

| 武器 | 伤害 | 弹匣 | 射速 | 特性 |
|---|---|---|---|---|
| 拳头 | 20 | — | 0.5s | 射程 2m |
| 手枪 | 25 | 12 | 0.35s | 精准单发 |
| 冲锋枪 | 12 | 30 | 0.09s | 散布 ±1.2° |
| 霰弹 | 8×8 弹丸 | 6 | 0.9s | 锥形 ±5°，15m 内有效 |

- 换弹 1.2–1.8s；备弹无限；爆头（头部胶囊）×2 伤害
- 所有角色 HP=100；玩家被击倒 → 「FLATLINED」红色 glitch 3 秒 → 原地重生、通缉清零
- NPC 死亡：倒地 20s → 1s 下沉淡出回收
- 帮派 NPC 武器：手枪/冲锋枪混配，命中玩家 8–15 伤（距离衰减）

## 5. 帮派与事件（原创虚构帮派）

| 帮派 | 色标 | 地盘 |
|---|---|---|
| 铁蛆 FERRO | 橙红 | Santo Domingo 工业区 |
| 鬼刃 ONI | 品红 | Westbrook/Japantown |
| 浪潮 TIDE | 青 | Pacifica |
| 金环 AUREL | 金 | Heywood |

Watson 为争夺区（多帮出没）。活性池分配：每帮 6 支 3–5 人小队沿地盘街区巡逻 + NCPD 双人巡组 8 组 + 事件预算单位。

**事件导演**（同时活跃 4–6 起，事件间隔 20–50s 补位）：
1. **街头斗殴**：2–4 人拳脚（挥拳=手臂摆动加剧，受击后仰，一方倒地事件结束围观散去）
2. **帮派枪战**：地盘边界街区，两帮小队对射 45–90s（散开走位、曳光交火、中弹倒地），打完撤离
3. **NCPD 交火**：巡逻组遭遇帮派小队概率开战
4. 既有静态案发现场保留（事后场景）；救援 AV 优先飞往刚结束的枪战点（联动）

**恐慌波**：任何枪声 → 300m 内人海行人奔跑（shader uniform 环，8s 衰减）。

## 6. 通缉

- ★：伤害平民/警察 → 附近 NCPD 活性单位追击开火；人海警察不参战
- ★★：累计 3 次敌对行为 → 一辆警车驶到最近路口卸下 4 名武装警员
- 衰减：连续 20s 未被任何警员"视线"（120m 无遮挡）命中判定 → 降 1 星
- 纯状态机实现（可测）；玩家死亡即清零

## 7. HUD 与可发现性

- 门头灯箱文字图集：吧/医/食/枪/网/宿/衣/仓/弹（2 字内，canvas 生成，实例 UV 偏移）

## 8. 表现与音效

- 命中：白色火花 3–5 粒 + 红色粒子 6–10 粒（0.4s 寿命，池化 512）
- 曳光弹：抛出方向短亮线（0.08s），枪口焰 1 帧灯箱
- 音效（WebAudio 合成）：手枪"砰"（噪声脉冲+低通）、冲锋枪连"哒"、霰弹闷响、命中"噗"、换弹双"咔"、玩家受击低鸣、通缉警笛远景循环（★≥1 时）
- 距离衰减 + 简单立体声 pan

## 9. 测试

- Vitest：damage 结算（部位系数/溢出/死亡）、weapons 状态机（射速节流/空仓/换弹打断）、hitreg 射线-胶囊与穿墙拒绝、wanted 升降级、gangs 地盘分配（小队全部在本帮区域内）、恐慌波参数纯函数
- Playwright：进入漫游 → 开火 → 弹药减少断言；命中活性 NPC → 倒地（venue 探针经 `__nc` 注入目标坐标）

## 10. 性能预算

活性池 160 单位 AI（0.1s 节流）+ 矩阵更新 ≈ 每帧 <0.5ms；粒子/曳光池化；命中反算仅按需（开火帧）；小地图 4Hz 重绘。恐慌波纯 shader。整体不改变现有 draw call 数量级。
